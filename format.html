Загрузка собственного среза

Откройте период вверху карты, раскройте «Загрузить данные», выберите файл JSON в UTF-8 и нажмите «Применить». Срезы доступны до закрытия или обновления вкладки. Файл обрабатывается в браузере. Для выбора следующего среза используйте поле «Доступные срезы».

Корневой объект содержит название источника в строке name и непустой массив slices. В каждом срезе обязательны следующие поля.

Поле Содержание
from, until Первая и последняя даты включительно, строки YYYY-MM-DD.
time all, morning, day, evening или night. Границы часов определяет поставщик, их можно уточнить в названии источника.
tourists, excursionists Два готовых неотрицательных целых итога. Категории должны быть взаимно исключающими и вместе составлять всех визитеров среза.
marks Массив объектов с уникальным целым id ≥ 0, строкой name и координатами WGS 84 в числовых полях lat, lon.
cells Массив прямоугольных ячеек. Числа south, west, north, east указывают границы WGS 84. Поле value содержит целое неотрицательное число визитеров в ячейке за срез.

Файл до 10 МБ. Период и время суток однозначно задают срез в одном файле. Городская подложка покрывает Нижний Новгород. Клик по импортированной ячейке показывает её точное значение. Значения ячеек не суммируются в городские итоги, поскольку человек мог посетить несколько мест.

Ниже минимальный импорт на числах с фотографии. Пустые массивы передают отсутствие геометрии в этой выгрузке.

{
  "name": "Январь 2025 · только сводка с фотографии",
  "slices": [{
    "from": "2025-01-01",
    "until": "2025-01-23",
    "time": "all",
    "tourists": 748151,
    "excursionists": 1689,
    "marks": [],
    "cells": []
  }]
}
