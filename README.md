# Карта мест притяжения Нижнего Новгорода

Откройте `index.html` для карты турпотока или `now.html` для карты «Что открыто сейчас». Для размещения на GitHub Pages укажите ветку `main` и папку `/ (root)` в Settings → Pages, если выбранный тариф и видимость репозитория поддерживают Pages. Сборка и сервер приложений не требуются.

## Что открыто сейчас

Карта получает именованные музеи, галереи, театры, парки, стадионы, аттракционы и терминалы с расписанием из OpenStreetMap через Overpass. Источник опрашивается при открытии, если последняя успешная проверка была более шести часов назад. В открытой вкладке карта проверяет необходимость запроса каждые 15 минут. Кнопка «Обновить справочник» запрашивает его сразу.

Статусы пересчитываются каждую минуту в часовом поясе Europe/Moscow. В цветной ячейке размером примерно 1 × 1 км показано количество объектов, открытых по расписанию. Клик по точке показывает исходную строку расписания и ссылку на объект. Слой охватывает объекты с известным расписанием в пределах выбранного городского прямоугольника. Записи OSM могут описывать как отдельное здание, так и территорию.

Поддерживаются еженедельные дневные интервалы, диапазоны дней, перерывы, выходные и 24/7. Праздничные, сезонные, ночные и неоднозначные правила получают статус «Уточните расписание». Встроенная копия содержит 52 расписания из выгрузки от 20 ноября 2026 года. Если сервис недоступен, используется последний сохранённый справочник с указанием даты. Расчёт описывает плановое открытие. Фактическая посещаемость требует отдельного источника. [Описание opening_hours](https://wiki.openstreetmap.org/wiki/Key:opening_hours) · [Авторство OpenStreetMap и ODbL](https://www.openstreetmap.org/copyright)

## Как подключить поток посещаемости

В `feed-config.js` укажите публичный адрес JSON в `ATTENDANCE_FEED_URL`. Подойдёт также файл `data/attendance.json`, который обновляет ваш поставщик. Внешний сервер должен разрешать чтение с домена карты через CORS. Ключи закрытого API хранятся на стороне поставщика или вашего сервера. В браузер передаётся подготовленная агрегированная выгрузка.

Структура `name` и `slices` описана в [формате выгрузки](format.md). Сетевой ответ также должен содержать `observedAt` — время измерения с часовым поясом, например `2026-11-20T12:00:00+03:00`. Первым в `slices` поставщик передаёт новейший срез. Пример структуры на фактически видимых числах старой фотографии:

```json
{
  "name": "Архивный пример с фотографии",
  "observedAt": "2025-01-23T23:59:59+03:00",
  "slices": [{
    "from": "2025-01-01", "until": "2025-01-23", "time": "all",
    "tourists": 748151, "excursionists": 1689, "marks": [], "cells": []
  }]
}
```

Время в примере условно и служит для демонстрации формата. Укажите фактическое время наблюдения в рабочем потоке. Браузер запрашивает JSON каждую минуту в активной вкладке. Нажмите «Показать последний срез» для просмотра потока. При изменении периода он переключится на новый срез. Сохранённый исторический выбор останется на своей дате. Для устаревшей записи и при сбое соединения интерфейс выводит статус. При отсутствии выгрузки по-прежнему доступна архивная карта.

## Архив

1–23 января 2025 года: 749 840 визитеров, в том числе 748 151 турист и 1 689 экскурсантов. Отдельно сохранены изображение карты, крупный план фотографии и [разбор 33 контуров](analysis.md). Архив включает поиск, масштаб, сравнение с фотографией, отдельные слои, импорт локальных выгрузок и экспорт отчётов.

Для проверки по HTTP из папки проекта запустите `python3 -m http.server 8000` и откройте `http://localhost:8000/`. Обе карты сохраняют базовую функциональность при открытии с диска.
